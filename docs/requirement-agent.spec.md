# 可使用工具的需求测试执行

## 问题和目标

旧执行器只让无工具模型选择静态操作目录，无法调查源码、解析用例代称或构造缺失前置；已有未执行结果无法重试，计划错误未保存具体字段。新的 `execution.mode=agent` 复用 Runner、资源授权、Codex app-server、变更台账和两个 Skill，在同一 Job 中完成调查、数据准备、执行、断言、清理与报告。通用执行器不包含业务项目的编号、金额、对象或接口。

## 契约

- 项目配置一次绑定源码根、非生产资源及凭据来源；工具只取得当前项目/环境/Job/用例身份，凭据保留于本机连接器。
- 模型可读取源码、发现接口/数据结构、查询真实数据、操作浏览器、运行受控 HTTP/数据库/消息/调度操作。业务写入必须先登记归属、独立回读、前置快照、恢复与恢复核验。
- 导航自动触发的写入与点击提交使用相同台账。已有测试对象可由项目资源一次授权恢复式写入，每次仍验证唯一 ID 与前置状态；不能用该授权创建无归属对象。源码搜索支持目录及单文件，工具错误须有可修正的字段诊断。
- 独立基线、多对象和多期间采用显式别名映射，每项断言关联步骤、主体、期间、渠道及来源。UI 断言不能用 API 替代。页面等待业务就绪而非仅元素存在。
- 计划是有版本的结构；错误保存脱敏输出及字段级诊断并反馈模型修正。不断有进展时没有整个任务的耗时/轮数上限；重复无进展可暂挂并保留证据。
- 旧尝试存档，重试按新 attempt 隔离；未决写入先对账。版本迁移只在原资源身份不变且无未决变更时进行，原发布回执和用例不改。
- 已核验发布表的三列执行批注允许由其他执行者维护，续跑存快照而不覆盖或冒充专员结果；用例正文、顺序、表头和附页变化仍阻断，并记录单元格差异。原发布版本与回执保留。
- 数据库日期/时间保持数据库原文及精度，不能因 JSON 脱敏丢成空对象或改变期间；非数据库 Date 值遵循标准 JSON 表达，历史观测不伪造补值。
- 正常、异常、停止后恢复均从台账清理并回查。清理不明不可完成或盲目重试。
- 连接器从真实登录回执提取项目配置的公开身份，随写意图保留；隐式当前用户目标仍须源码、身份和快照共同证明。恢复换会话时核对原身份，不向其他用户重放恢复。令牌不作为公开身份输出。
- HTTP 观测保留脱敏的实际查询参数及请求体，快照可定位到被查询对象；页面断言及主体身份只取 DOM values，附有截图也不能把网络响应字段当作页面实测。
- 同 Job 历史观测可回读供调查，但旧尝试不能绑定新别名、前置基线或断言；同契约已审核操作可复用，新任务知识仍须核实。
- 重试接收最近一次尝试的脱敏工具错误、参数和证据引用，避免只复用旧计划却丢掉修正依据；缺失历史诊断如实标注不可用，不能编造恢复。旧错误和观测均不算本次实测。
- 根仓 Git 忽略规则不应隐藏已配置项目内的业务子仓，凭据与依赖排除保持；搜索和枚举均适用。
- 原话题显式「重试失败」重跑失败及未执行项、继续未处理项；保留同 Job、旧尝试、已通过项及发布回执。未决副作用拒绝重试。
- SQL 基线与实测必须有可比口径；查询或字段差异先独立审查，不传入实测值影响判断。测量错误可重新查询，真实业务断言失败保持。
- 计划可回读及局部修正主体，不改冻结预期；字段错误与全部候选留档，已比较主体不能改。
- 断言前独立核对实际字段语义与业务指标：页面元素数量不能当金额，已申请不能当剩余，状态码不能当业务值。页面保留DOM、读取方式和匹配数量，API依据实际请求及源码响应定义，SQL依据实际查询投影；错误绑定先修正，不生成业务失败。
- 字段审查接收Runner从本次实际观测核对的主体路径和值，以及同一原始预期行的冻结拆分检查。已核实同一数组行的身份不依赖固定排序；其他行身份不能为当前取值背书。组成项可以共同证明复合条件，仍须逐项实测，不能以兄弟检查替代当前指标。实际业务值和冻结期望不因上下文补全而变化。
- SQL字段审查同时获得已检查的同资源、同数据库、查询所涉及表的列及索引结构，用于核实字段覆盖和唯一约束；结构不能替代查询口径、截断风险或实际业务结果验证。
- 字段及口径审查可通过 `evidenceRefs:[{observationId,fields}]` 接收本次真实观测中的辅助字段，如摘要长度、记录数、截断和状态信息；Runner验证当前尝试及实际字段存在，附带来源查询和时点，不接受模型直接填写证据值。辅助证据不能替代被测指标、主体或冻结预期。
- 数值实际值可由已观测字段按显式正负号计算，保留全部操作数和精确十进制结果；冻结预期仍独立不变。页面要求直接展示时，计算不能代替可见值。经核实的缺失字段记null与missing，不能伪造0。
- 派生计算可为实际null声明 `nullAs:{value,reason}` 并提交源码引用，经独立语义核验后计算，证据同时保留原始null、转换规则和实际参与计算的数值。只有业务明确的空值语义可以转换，DTO默认值或预期值不构成依据；缺失路径、空字符串、未知值、已有数值与失败HTTP响应均不能被替换。该规则不改变原始API字段断言或页面展示要求。
- MySQL混合参数不因DOUBLE重准备损坏大整数目标，已舍入整数输入不得写入；行数不符必须回滚并展示具体行数，恢复后相邻对象保持不变。未使用的查询属性能力不参与连接协商。
- 发布信息仍按用例前置处理，缺构建号/镜像及 CNB 权限不是全局执行门槛。

## 验证与交付

先复现 UI/API 错配、多主体、异步读取、计划修正、丢回执、清理失败和未执行重试。模块替身结果与真实模型/Runner/工具隔离整链分别记录。部署前检查在途任务和未决变更，备份程序、配置、状态；上线核对源码指纹、飞书原话题入口及原 Job。实际业务由专员执行，原 19 条各自记录通过、失败、阻断、未执行，按原 Skill 固定 15 表交付。
