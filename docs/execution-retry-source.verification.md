## 操作及证据语义

- 原发起人以原话题的「重试阻断」新建同 Job 的尝试。对任务级暂停或等待的继续，以及失败和未执行的重试，原命令各自保持。未决台账须先用原绑定核验清理，普通重试不恢复取消状态。
- 静态目录的失败和缺口可同时存在。未比较检查按缺证据、不可比或未执行保留，未知 HTTP 响应不形成产品失败。外部服务和工具诊断与运行时不符分别出现在报告和通知。
- 当前用例指向自身尝试。旧尝试继续引用旧文件，当前报告的证据索引区分历史及当前。工作簿与归一化输入按报告 ID 保留。同 Job 重试文件名附加序号以防覆盖。报告区分运行的 AgentOS 版本、被测源码与独立的服务端部署证据。
- 物理工作树文件的字节摘要说明本次读到的内容。工作树 HEAD 是取证上下文。显式 Git ref 按解析出的提交读取不可变 blob。源码路径与内容仍经现有凭据过滤，报告证据保存摘要和路径，避免复制源码或凭据。
